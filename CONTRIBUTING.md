# Contributing

Thanks for helping people stop overpaying for medicine! Contributions of every size are welcome, including Hacktoberfest PRs.

## Ground rules (please read)

- **Never add drug facts generated by an AI model.** Every generic name, strength and price must come from a cited public source and live in `src/data/`.
- **Never add substitution advice.** We show prices and molecules only.
- **Never log or store user images.**
- Keep PRs small: one change per PR, with a clear title.

## Setup

1. Install [Node.js 20+](https://nodejs.org/) and Git.
2. Fork the repo, then clone your fork:
   ```bash
   git clone https://github.com/<you>/<repo>.git
   cd <repo>
   npm install
   ```
3. Copy the environment file and edit it if needed:
   ```bash
   cp .env.example .env        # PowerShell: Copy-Item .env.example .env
   ```
4. Start the app:
   ```bash
   npm run dev                 # http://localhost:5173
   ```
5. To test offline mode, build and preview, open the app once, then turn on aeroplane mode / DevTools → Network → Offline:
   ```bash
   npm run build
   npm run preview             # http://localhost:4173, also on your LAN for phone testing
   ```
6. (Optional) Photo scan: either install [Ollama](https://ollama.com/) and run `ollama pull gemma4:e2b`, or put a Google AI Studio key in `.env` with `GEMMA_PROVIDER=hosted`. Then run `npm run server` in a second terminal. See "Run it" in the [README](README.md).
7. Run the tests before opening a PR: `npm test`.

## Project layout

```
src/components/   UI components
src/data/         bundled drug dataset (JSON) — the only source of drug facts
src/lib/          search, matching, validation helpers
src/i18n/         hi.json / en.json strings
server/           small Express proxy for Gemma (validation, size + rate limits)
scripts/          data-cleaning and build scripts
```

## Commits and PRs

- Small, honest commits in the imperative mood: `Add Fuse.js brand search`.
- Describe what you changed and how you tested it (ideally on a phone-sized screen).
- Link the issue you are fixing.

## Good first issues

- 🌐 **Add a language:** copy `src/i18n/en.json` to e.g. `bn.json`/`ta.json` and translate it.
- 💊 **Add drugs to the dataset** from a cited public source (include the source URL in the PR).
- 🔤 **Add common misspellings / Hindi spellings** for brand names to improve fuzzy matching.
- ♿ **Accessibility pass:** check contrast, labels and screen-reader text.
- 🧪 **Add tests** for the matching and validation functions in `src/lib/`.
- 📍 **Jan Aushadhi Kendra locator:** a data-driven list of nearby Kendras (offline JSON).
- 📸 **Improve scan prompts** for blurry or angled strip photos (output must still be validated).
